# Lumos Study AI

Lumos Study AI is a minimalist educational tool that uses artificial intelligence to transform raw text into concise study kits, featuring flippable flashcards and interactive practice quizzes for focused learning.

## Features

- **Source Analysis:** Automatically extracts key insights from long-form text.
- **Active Recall Flashcards:** Minimalist cards designed for term and definition mastery.
- **Practice Quizzes:** Instant multiple-choice tests with explanations to validate your knowledge.
- **Clean Minimalism:** A distraction-free environment for deep focus.

## How to use

1. Paste your study notes or article into the input area.
2. Click **Generate** to create your study kit.
3. Switch between **Flashcards** and **Practie Quiz** using the sidebar.
4. Click flashcards to flip them and test your memory.

## Setup

1. Add your `GEMINI_API_KEY` to the environment variables.
2. Run `npm install` and `npm run dev` to start the development server.
